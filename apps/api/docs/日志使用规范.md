# 日志使用规范

## 1. 概述

本项目强制使用 Winston Logger，禁止在业务代码中使用 `console.*`。

## 2. 使用场景

### 2.1 Service 层（推荐方式）

通过依赖注入使用 Winston Logger：

```typescript
import { Injectable, Inject } from '@nestjs/common';
import { WINSTON_MODULE_PROVIDER } from 'nest-winston';
import { Logger } from 'winston';

@Injectable()
export class MyService {
  constructor(
    @Inject(WINSTON_MODULE_PROVIDER) private readonly logger: Logger,
  ) {}

  doSomething() {
    this.logger.info('Operation started', { userId: '123' });
    this.logger.error('Operation failed', { error: err.message });
  }
}
```

### 2.2 模块初始化阶段

在 Module 的 `useFactory` 中无法注入 Logger，使用 `standaloneLogger`：

```typescript
import { createContextLogger } from '@/utils/logger-standalone.util';

const logger = createContextLogger('RedisModule');

@Module({
  providers: [
    {
      provide: REDIS_CONNECTION,
      useFactory: async () => {
        const client = new Redis(url);
        
        client.on('connect', () => {
          logger.info('Redis client connected');
        });
        
        client.on('error', (error) => {
          logger.error('Redis connection error', { error: error.message });
        });
        
        return client;
      },
    },
  ],
})
export class RedisModule {}
```

### 2.3 允许使用 console 的场景

以下场景**允许**使用 `console.*`：

| 场景 | 文件位置 | 原因 |
|------|----------|------|
| 应用启动 | `main.ts` | Logger 未初始化 |
| 数据库种子 | `prisma/seed.ts` | 独立脚本 |
| 迁移脚本 | `scripts/*.ts` | 独立脚本 |
| 测试代码 | `*.spec.ts` | 测试输出 |
| 文档示例 | `*.md` | 示例代码 |

## 3. 日志级别

| 级别 | 使用场景 |
|------|----------|
| `info` | 正常业务流程、状态变更 |
| `warn` | 潜在问题、可恢复的异常 |
| `error` | 错误、异常、需要关注的失败 |
| `debug` | 调试信息（仅开发环境） |

## 4. 日志格式

推荐使用结构化日志：

```typescript
// ✅ 推荐：结构化日志
this.logger.info('User logged in', { 
  userId: user.id, 
  ip: request.ip 
});

// ❌ 不推荐：字符串拼接
this.logger.info(`User ${user.id} logged in from ${request.ip}`);
```

## 5. ESLint 规则

项目已配置 `no-console` 规则：

```javascript
// .eslintrc.js
{
  rules: {
    'no-console': ['error', { allow: ['warn', 'error'] }],
  },
  ignorePatterns: [
    'scripts',          // 独立脚本
    'prisma/seed.ts',   // 种子数据
    'generated',        // 自动生成的代码
  ],
}
```

## 6. 快速替换指南

```typescript
// 替换前
console.log('Connected');
console.error('Error:', error);
console.warn('Warning message');

// 替换后（Service 层）
this.logger.info('Connected');
this.logger.error('Error', { error: error.message });
this.logger.warn('Warning message');

// 替换后（模块初始化）
logger.info('Connected');
logger.error('Error', { error: error.message });
logger.warn('Warning message');
```
